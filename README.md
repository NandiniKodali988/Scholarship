# Conflict and Compassion: A Deeper Dive into Attacks on Aid Workers

This project explores over 25 years of global attacks on humanitarian aid workers, providing an interactive, data-driven narrative of how violence against aid workers has escalated across regions, actors, and conflict context. 

The goal is to deliver actionable insights for humanitarian organizations and security analysts by examining trends, regional variations, perpetrators, and attack methods.
